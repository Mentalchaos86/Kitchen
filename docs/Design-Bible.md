# HomeHub Design Bible

## Core Hierarchy

1. One hero mission
2. One supporting item
3. Supporting dashboard information

## Three-Second Rule

Every main-screen element must be understandable in under three seconds.

## Color Meaning

- Red: live or urgent
- Orange: soon or action needed
- Blue: tomorrow or travel
- Purple: future milestone
- Green: completed
- Neutral: calm or clear day

## Motion

Animations must be calm, brief, non-looping, and communicate state changes.

## Main Rule

If a feature makes the user read more, it probably belongs somewhere else.
