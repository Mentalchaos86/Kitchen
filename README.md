A premium visual redesign of the working kitchen dashboard.

## Improvements

- Cleaner full-screen 16:9 layout
- Larger text and stronger contrast for viewing across the kitchen
- Refined glass-style cards
- Better spacing and visual hierarchy
- Subtle day and night appearance
- Improved Bitcoin panel
- Refined countdown card
- Existing calendar, events, weather, shopping list and That’s Gaming feed retained
